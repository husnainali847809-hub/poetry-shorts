# Qawwali audio folder

Add original Qawwali audio files here for the scheduled Qawwali videos.

Supported formats: MP3, M4A, WAV, OGG, FLAC.

The generator checks this folder first and uses the first valid audio file. If no usable local audio exists, it tries the online audio search fallback.

Only add audio you have permission to publish. The automatic license filter is disabled, but copyright rules still apply.
